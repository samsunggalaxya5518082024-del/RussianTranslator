# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-09-09

### Added
- Initial release
- Accessibility Service for real-time text translation
- English to Russian translation dictionary with 150+ words
- Toggle on/off functionality
- Main activity UI with status display
- Accessibility Service configuration
- CI/CD workflow with GitHub Actions
- Comprehensive documentation and README
- Contributing guidelines
- MIT License

### Features
- Translates English words to Russian across all apps
- Works in real-time as you interact with applications
- Minimal battery and memory usage
- User-friendly interface with easy enable/disable
- Extensive built-in dictionary

### Technical Details
- Built with Kotlin and Android SDK
- Minimum Android version: 16
- Uses AccessibilityService API for system-wide text monitoring
- HashMap-based dictionary for O(1) lookup time
