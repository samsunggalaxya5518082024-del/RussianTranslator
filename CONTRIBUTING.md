# Contributing to Russian Translator

Thank you for your interest in contributing! Here's how you can help:

## Reporting Bugs

1. Check if the bug already exists in Issues
2. Provide a clear description
3. Include steps to reproduce
4. Specify your Android version and device

## Adding New Features

1. Open an issue to discuss the feature
2. Fork the repository
3. Create a feature branch: `git checkout -b feature/your-feature`
4. Commit your changes: `git commit -am 'Add feature'`
5. Push to the branch: `git push origin feature/your-feature`
6. Submit a Pull Request

## Expanding the Dictionary

To add more word translations:

1. Edit `TranslationDictionary.kt`
2. Add your word pairs to the `dictionary` map
3. Follow the format: `"english word" to "русское слово"`
4. Test with various apps
5. Submit a PR with your additions

## Code Style

- Use Kotlin conventions
- Add comments for complex logic
- Test your changes before submitting
- Keep files organized and readable

## Pull Request Process

1. Update README if needed
2. Add comments for new code
3. Test on actual Android devices
4. Ensure no compiler errors
5. Request review from maintainers
