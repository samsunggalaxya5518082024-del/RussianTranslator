# Russian Translator

Android app for real-time text translation to Russian using Accessibility Service.

## Features

- Real-time translation of 10+ languages to Russian
- Accessibility Service integration
- Easy toggle on/off
- Automatic permission requests
- Built with Kotlin

## Build

```bash
./gradlew assembleDebug
./gradlew installDebug
```

## Setup

1. Install the app
2. Open app and grant permissions
3. Enable Accessibility Service: Settings > Accessibility > Russian Translator
4. Toggle translation ON

## Supported Languages

English, Spanish, French, German, Japanese, Korean, Arabic, Chinese, Turkish, Italian
